# Intro to Logic

Course materials for **Methods 1 – Logic** at the University of Tübingen (*winter semester 2026/2027*).

**Lecturer:** [Kyle Richardson](https://www.krichardson.me/)
**Time and location:** Tuesdays 14:00–16:00, Hörsaal 0.02 (VG Wilhelmstraße)

## Schedule and slides

The **Core Readings**, which cover the main content of the course, can
be found all together
[here](https://michael-franke.github.io/logic-materials/). Links to
supplementary reading materials are provided below. It is expected
that students read the Core Reading materials each week and follow
closely the slides and corresponding lectures (*additional readings
